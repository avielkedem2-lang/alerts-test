בחירת mongodb:
אני הייתי יכול להשתמש ב sql הסיבה שלא בחרתי כי לא ראתי צורך להשתמש ברלציוני לכן השתמישתי באירלציוני.





קודי סטטוס:
400 => כשאשר הלקוח שלח בקשה שהיא לא לפורמט.

200 => כאשר הלקוח שלח בקשה וקיבל בהצלחה את התשובה.

201 => כאשר הלקוח ניסה ליצור משהו חדש.

404 => כאשר הלקוח שלח בקשה שדורשת חיפוש כל שהו ולא נמצא שום דבר.

401 => כאשר הלקוח שלח משהוא שהוא בעייתי.





כללים שהגדרתי:
ברגע שהלקוח שולח בקשה המערכת מקבלת את זה ובודקת האם זה מתאים לפורמט או האם הטוקן תקין
אחרי כל הבדיקות מחזרין את מה שצריך ואם משהוא לא היה תקין אז אני שולח לא הודע איפה היה הבעיה.
